## Estructura del repositorio
- **laboratorios/**: contendrá los cinco laboratorios evaluativos del curso.
- **ejercicios-clase/**: almacena los ejercicios prácticos realizados durante las clases.
- **benchmarks/**: incluye scripts para medir tiempos de ejecución y generar gráficas utilizadas en los laboratorios.
- **.gitignore**: incluye los patrones de archivos que no se desean versionar, como `__pycache__/`, `.vscode/`, entre otros.
